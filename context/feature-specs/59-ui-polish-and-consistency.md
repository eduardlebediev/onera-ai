# Feature: UI Polish and Consistency Pass

## Goal

Unify admin and employee UI around the admin dashboard reference: spacing rhythm, button styling, KPI presentation, table toolbars, page headers, and test-result layout. Remove dead or redundant UI and wire primary header actions to real routes.

## User story

As an admin or employee using Ontera AI, I want every list page, detail page, and action button to feel like one product, so that navigation, spacing, and controls are predictable without relearning patterns per screen.
